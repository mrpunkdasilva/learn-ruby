# 📱 Conteúdo para Redes Sociais

Esta pasta contém textos e materiais para divulgação do Learn Ruby nas redes sociais.

## 📂 Estrutura
```
social-media/
├── linkedin/
│   ├── posts/
│   └── images/
├── twitter/
│   ├── posts/
│   └── images/
└── templates/
    ├── post-template.md
    └── hashtags.md
```

## 📝 Guidelines
- Posts LinkedIn: 1300 caracteres máx
- Posts Twitter/X: 280 caracteres máx
- Sempre incluir hashtags relevantes
- Usar emojis com moderação
- Incluir call-to-action (CTA)
