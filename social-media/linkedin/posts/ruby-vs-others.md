⚡ Ruby vs Outras Linguagens: Por que escolher Ruby?

🎯 Ruby se destaca por:

1️⃣ Expressividade
```ruby
# Ruby
5.times { puts "Hello" }

# Vs outras linguagens
for(i=0; i<5; i++) {
  console.log("Hello");
}
```

2️⃣ Princípio da Menor Surpresa
```ruby
["a", "b", "c"].first #=> "a"
["a", "b", "c"].last  #=> "c"
```

3️⃣ Tudo é um Objeto
```ruby
5.methods       #=> Lista todos os métodos disponíveis
"hello".upcase  #=> Até strings são objetos!
```
